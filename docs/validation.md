## 有意义的测试内容

- 增强：非方形旋转与翻转、裁剪可见率边界、resize 上下采样、mask 类别值、RGBA alpha、框与标签过滤、调用方缓冲区不变。
- 确定性：固定 seed/sample ID、概率为零、256/257 步边界、序列化 replay、版本/输入形状/随机操作非法记录。
- 采样：多 batch、多 channel、不同输出尺寸、零填充、极远坐标、单像素轴、两种角点模式。
- 梯度：输入、grid、theta 的 CPU PyTorch Double 对照和独立有限差分审计；不光滑点采用明确边界约定。
- 输入：非法 JSON、严格整数、非有限数、shape 溢出与长度不匹配、资源上限、错误类型和非法参数。
- 配准：损失单调下降、返回参数和输出一致、从小幅旋转和平移恢复已知合成目标。

## 实际演示结果

浏览器默认 48×48 三高斯样本，目标旋转 12°、归一化平移 x=0.12/y=-0.08，六参数从单位矩阵开始，学习率 0.5、300 步。MSE 从约 **0.016866** 降至 **4.1710e-10**。这是特定合成样本结果，不代表任意真实图像的收敛保证。

耗时仅在页面展示当前运行结果，不作为跨设备性能承诺。浮点一致性允许包文档所述容差；resize/颜色参考允许一个 uint8 灰阶差，mask 和同记录重放要求精确一致。

## 交付范围

本版本实现二维、CPU/JS/Wasm 可用的有限能力集合：字节图像增强和一阶可微采样。没有把 GPU、通用神经网络训练、图像 codec、反射边界、三维采样或高阶梯度标成已实现。完整公共 API、资源上限与坐标约定均在各包 README 中列出。
